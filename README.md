Assignment 3: Secure Authentication System

User Guide

## Step 1: Database Setup

1. Open MySQL Workbench
2. Run the provided SQL script located in `database/schemasql` to create the `secure_auth_db` database and `userinfo` table

## Step 2: Configure database credentials

1. Open the project in Intellij IDEA
2. Navigate to the DatabaseConnection class
3. Update the database URL, username, and password to match your local environment

## Step 3: Running the application

1. In IntelliJ IDEA, location the main class `Main.java`
2. Right click the file and select `Run Main.main()`
3. Observe the console output demonstration registration and login verification.
