Assignment 3: Secure Authentication System

User Guide

## Step 1: Database Setup

Open MySQL Workbench
Run the provided SQL script located in `database/schemasql` to create the `secure_auth_db` database and `userinfo` table

## Step 2: Configure database credentials

Open the project in Intellij IDEA
Navigate to the DatabaseConnection class
Update the database URL, username, and password to match your local environment

## Step 3: Running the application

In IntelliJ IDEA, location the main class `Main.java`
Right click the file and select `Run Main.main()`
Observe the console output demonstration registration and login verification.
